# RoadAware backend

ส่วนข้อมูล แบบจำลอง และ API ของ RoadAware — ภาพรวมและวิธีรันอยู่ใน [README หลัก](../README.md)

| ขั้น | Notebook | ทำอะไร |
|---|---|---|
| ข้อมูลพื้นฐาน | 01–05, 09–10 | เก็บข้อมูล สำรวจ ทำความสะอาด แบ่งชุดข้อมูล ตรวจ leakage ปัจจัยภายนอก |
| แบบจำลองระดับจังหวัด | 06–08, 11–13 | ทดลองและประเมินแบบจำลองระดับจังหวัด (ใช้เป็นส่วนเสริมของ API) |
| ถนนและการจับคู่ | 16–18 | ความพร้อมของพิกัด เก็บเส้นทางหลวง จับคู่อุบัติเหตุกับช่วงถนน |
| แบบจำลองรายช่วงถนน | 19–22 (`*_national`) | เตรียมข้อมูล ทดลอง HGB ประเมิน/กำหนดสีระดับ และโหลดใช้งาน |
| ประวัติและ API | 14, 24 | สถิติที่ผ่านมาของแต่ละช่วงถนน และสัญญาของ API |
| ทดสอบข้อมูลใหม่ | 23 (`_national`) | ประเมินกับบันทึกปี 2569 |

ตรรกะทั้งหมดอยู่ในเซลล์ `# FUNCTIONS` ของ notebook; `scripts/run_*.py` รัน notebook แบบ headless และเขียนผลลงโฟลเดอร์ใหม่ `backend/rerun-*` เสมอ (ไม่ทับผลเดิม)
API (`api/`, เปิดด้วย `scripts/run_api_server.py --national`) ตรวจ hash ของทุกไฟล์ตาม `../workflow/api/input-pins-v4.json` ก่อนโหลดแบบจำลอง
