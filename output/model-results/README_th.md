## 1. Baseline และ Candidate Models

ใช้ภาพ **01_model_comparison.png** และตาราง `model_comparison_exact.csv`

ทดสอบ 3 ตระกูล ได้แก่ Poisson Regression, Random Forest ที่ใช้ Poisson criterion และ HistGradientBoostingRegressor (HGB) ที่ใช้ Poisson loss โดยเลือกตัวแทนที่ดีที่สุดของแต่ละตระกูลจากผล OOF เท่านั้น Poisson ทดลอง alpha 0.001 และ 0.01; แต่ละ configuration ทดลอง 5 ชุด features รวม 20 candidate methods ต่อหน่วย และ 6 baselines ต่อหน่วย ไม่ได้มีเพียงการทดลอง 3 ครั้ง

- Poisson Regression: จุดเริ่มต้นสำหรับทำนายจำนวนเหตุการณ์ ค่อนข้างเรียบง่าย ผลทำนายไม่ติดลบ และเป็นเส้นฐานโมเดลที่อธิบายได้ง่าย
- Random Forest: รวมต้นไม้หลายต้นเพื่อจับความสัมพันธ์ที่ไม่เป็นเส้นตรง
- HGB: สร้างต้นไม้เพิ่มทีละรอบเพื่อแก้ข้อผิดพลาดของรอบก่อน จับความสัมพันธ์ระหว่างพื้นที่ ปฏิทิน และ features อื่นได้ โดยเลือกด้วยผลทดลอง ไม่ใช่เลือกเพราะโมเดลซับซ้อนกว่า

Baseline รายวัน: `baseline_province_month_k30` คือค่าเฉลี่ยจำนวนบันทึกตามจังหวัดและเดือน โดย shrink กลับไปยังค่าเฉลี่ยจังหวัดด้วยน้ำหนัก k=30 ส่วนราย 6 ชั่วโมง: `baseline_province_block_mean` คือค่าเฉลี่ยตามจังหวัดและช่วง 6 ชั่วโมง ใช้เฉพาะข้อมูลฝึกที่อนุญาตในแต่ละ fold ทั้งสองเป็น strongest nonzero baseline ที่เลือกด้วย pooled OOF Poisson deviance ในหน่วยของตัวเอง

คำพูดแนะนำ: “เราให้โมเดลทั้งสามแข่งขันกับ baseline ที่แข็งแรง ไม่ได้เทียบกับการเดาสุ่ม และใช้ผลนอกชุดฝึกตามลำดับเวลาในการตัดสิน”

## 2. Evaluation Metrics

ใช้ภาพ **02_error_metrics.png**

| ตัวชี้วัด | ความหมายและวิธีอ่าน |
|---|---|
| Mean Poisson deviance | ตัวชี้วัดหลักสำหรับทำนายจำนวนเหตุการณ์ ค่าต่ำดีกว่า ใช้จัดอันดับโมเดล ไม่ใช่ร้อยละความแม่นยำ |
| MAE | ค่าเฉลี่ยของขนาดความคลาดเคลื่อน เช่น daily HGB = 0.6601 หมายถึงคลาดเคลื่อนเฉลี่ยประมาณ 0.66 เหตุการณ์ต่อจังหวัดต่อวัน ในเซลล์ที่เข้าเกณฑ์ประเมิน |
| RMSE | รากที่สองของค่าเฉลี่ยความผิดพลาดยกกำลังสอง ให้โทษความผิดพลาดขนาดใหญ่มากกว่า MAE ค่าต่ำดีกว่า |
| Signed bias | ค่าเฉลี่ย prediction − actual ค่าลบคือทำนายต่ำไป ค่าบวกคือทำนายสูงไป ใกล้ศูนย์ดีกว่า แต่ความผิดพลาดบวกและลบอาจหักล้างกัน |
| WAPE (มีใน CSV) | ผลรวม absolute error / ผลรวม actual; ไม่ใช่ accuracy และอาจเกิน 100% ได้ |

ข้อควรอธิบาย: baseline ที่ทำนายศูนย์เสมอมี MAE ราย 6 ชั่วโมงเพียง 0.1739 ต่ำกว่า HGB 0.2578 เพราะข้อมูลเบาบางและมีศูนย์จำนวนมาก แต่พลาดเหตุการณ์ที่เกิดจริงทั้งหมด จึงไม่ตัดสินด้วย MAE อย่างเดียว ค่า Poisson deviance ของ zero baseline ไม่ได้รายงานเป็นค่าปกติ เนื่องจากมี actual > 0 ขณะที่ทำนาย 0

ห้ามนำ MAE หรือ deviance รายวันไปเทียบตรง ๆ กับราย 6 ชั่วโมง เพราะเป็นคนละหน่วยเป้าหมาย

## 3. Experiment Results

ใช้ภาพ **01**, **03_temporal_folds.png**, **04_feature_experiments.png** และ **08_seen_year_diagnostics.png**

หลักฐานเลือกโมเดล: expanding time OOF 4 folds คือ 2022H1, 2022H2, 2023H1 และ 2023H2 ใช้ข้อมูลก่อนช่วงประเมินในการฝึก คะแนน pooled ถ่วงตามจำนวนแถวจริง ไม่ใช่ค่าเฉลี่ยของคะแนน fold แบบน้ำหนักเท่ากัน จำนวนเซลล์ประเมินรวม 53,610 รายวัน และ 214,440 ราย 6 ชั่วโมง เลือกโมเดลและล็อกก่อนเปิดดูผล diagnostic ปี 2024/2025

| หน่วย | วิธี | Poisson deviance ↓ | MAE ↓ | RMSE ↓ |
|---|---|---:|---:|---:|
| จังหวัด–วัน | strongest baseline | 1.1464 | 0.6894 | 1.0099 |
| จังหวัด–วัน | Poisson, full | 1.0896 | 0.6792 | 0.9908 |
| จังหวัด–วัน | Random Forest, full | 1.1278 | 0.7010 | 0.9854 |
| จังหวัด–วัน | **HGB, full** | **1.0643** | **0.6601** | **0.9535** |
| จังหวัด–6 ชั่วโมง | strongest baseline | 0.6078 | 0.2676 | 0.4569 |
| จังหวัด–6 ชั่วโมง | Poisson, full | 0.5963 | 0.2677 | 0.4539 |
| จังหวัด–6 ชั่วโมง | Random Forest, full | 0.6018 | 0.2637 | 0.4523 |
| จังหวัด–6 ชั่วโมง | **HGB, calendar_traffic** | **0.5835** | **0.2578** | **0.4478** |

คำพูดแนะนำ: “HGB ลด Poisson deviance เทียบกับ strongest baseline ได้ 7.16% ในรายวัน และ 3.99% ในราย 6 ชั่วโมง พร้อมชนะครบ 4 folds ในทั้งสองหน่วย” ห้ามพูดว่า accuracy เพิ่ม 7.16% หรือทำนายอุบัติเหตุถูก 96%

ภาพ 04 แสดงการทดลองเพิ่ม feature groups ของ HGB จริง ได้แก่ core, calendar, calendar_weather, calendar_traffic และ full; full คือรวม calendar/weather/traffic ส่วน core เป็น features พื้นฐานตาม protocol ไม่ใช่โมเดลอีกตระกูล รายวันเลือก full ส่วนราย 6 ชั่วโมงเลือก calendar_traffic จึงไม่มีข้อสรุปว่าเพิ่มทุก feature แล้วต้องดีกว่าเสมอ

ภาพ 08 เป็น **seen diagnostics**: ปี 2024 และ 2025 เคยถูกใช้/เห็นระหว่างพัฒนาแล้ว ไม่ใช่ untouched future test และไม่ได้ใช้เปลี่ยนผู้ชนะ ปี 2024 มี eligible daily cells 7,885 จาก 28,182 (~28.0%) ครอบคลุม 103 วันในมกราคม–กันยายน จึงไม่ใช่ผลประเมินเต็มปีที่สมบูรณ์

## 4. Error Analysis

ใช้ภาพ **05_calibration.png**, **06_festival_error.png**, **07_time_of_day.png**, **10_high_count_errors.png**

- **Calibration:** จุดเหนือเส้นทแยงคือทำนายต่ำกว่าที่เกิดจริง จุดใต้เส้นคือทำนายสูงไป แต่ละจุดเป็นค่าเฉลี่ยในกลุ่มค่าทำนาย ไม่ใช่การทำนายถูกของอุบัติเหตุแต่ละเหตุการณ์ ใช้ขอบ bins จาก OOF คงเดิมกับปีหลัง
- **เทศกาล:** daily HGB ในวันสงกรานต์ OOF มี actual 956 เหตุการณ์จาก 388 province-day cells แต่ทำนายรวมประมาณ 787.92 เหตุการณ์ (actual เฉลี่ย 2.46 vs predicted 2.03) และมีแนวโน้มทำนายสูงก่อนเทศกาล จึงมีปัญหาทั้งขนาดยอดและจังหวะเวลา ไม่ได้พลาดด้วยทิศทางเดียวทุกช่วง
- **ช่วงเวลา:** ราย 6 ชั่วโมงช่วง 00–06 มี bias ประมาณ −0.0118 เหตุการณ์/เซลล์ ส่วน 18–24 ประมาณ +0.0090 ควรดูขนาดจริง ไม่ขยายความต่างเล็ก ๆ ให้ดูเป็นความเสี่ยงส่วนบุคคล
- **เหตุการณ์จำนวนสูง:** daily ที่ actual ≥5 มี actual รวม 5,838 แต่ HGB ทำนายรวมประมาณ 2,729.89 จาก 904 เซลล์ แสดงการทำนายต่ำในยอดสูงชัดเจน กลุ่มนี้นิยามย้อนหลังจาก actual เท่านั้น ไม่สามารถรู้สมาชิกกลุ่มจากอนาคตหรือใช้เป็น input feature ได้

คำพูดแนะนำ: “คะแนนเฉลี่ยดีขึ้น แต่โมเดลยังพลาดช่วงยอดสูงและบางเทศกาล เราจึงแสดงข้อผิดพลาดเป็นรายกลุ่มและไม่อ้างว่าระบบพร้อมให้คำแนะนำความปลอดภัยรายเส้นทางแล้ว”

## 5. เหตุผลในการเลือกโมเดล

ใช้ภาพ **09_selection_evidence.png** ร่วมกับ **01** และ **03**

เลือก **HistGradientBoostingRegressor (Poisson loss)** แยกสองชุด:

- Daily: `hgb_poisson__full`
- 6h: `hgb_poisson__calendar_traffic`

เหตุผลที่อ้างอิงหลักฐานได้: มี pooled OOF deviance ต่ำที่สุดของ candidate families ที่ทดลอง, MAE/RMSE ต่ำกว่า strongest nonzero baseline, ชนะ 4/4 folds และผ่านเกณฑ์ที่ล็อกไว้ทั้งหมด ได้แก่ deviance ดีขึ้นอย่างน้อย 1%, MAE ไม่เกิน 1.02 เท่าของ baseline, ชนะอย่างน้อย 3/4 folds และขอบบนของ bootstrap interval ของ deviance difference ต่ำกว่าศูนย์

95% paired 7-day block bootstrap (500 resamples, seed 42), นิยาม difference = HGB − baseline:

- Daily: −0.08212, interval [−0.13628, −0.04229]
- 6h: −0.02423, interval [−0.04122, −0.01081]

Bootstrap เป็นการสำรวจหลังเลือก configuration/feature set ไม่ได้ปรับ multiple comparisons จึงไม่ควรอ้างว่าเป็นการยืนยันเชิงสถิติขั้นสุดท้าย หรือพิสูจน์ความสามารถบนอนาคตที่ไม่เคยเห็น

## ขอบเขตที่ต้องพูดให้ตรงกับงานจริง

งานนี้ทำนาย **จำนวนบันทึกอุบัติเหตุ MOT ที่อยู่ในชุดข้อมูลที่เลือก ในระดับจังหวัดและช่วงเวลา** ยังไม่ใช่ความน่าจะเป็นการเกิดอุบัติเหตุของผู้เดินทางคนหนึ่ง ไม่ใช่อุบัติเหตุครบทุกถนน และไม่ใช่หลักฐานความเสี่ยงรายจุดบนเส้นทาง ข้อมูล AADT เป็น proxy รายปีจากสถานี ไม่ใช่จำนวนรถสด; สภาพอากาศที่ใช้ในงานทดลองมี coverage จำกัดและไม่มีใน diagnostics ปี 2024/2025 จึงยังอ้างประโยชน์ของ weather feature แบบทั่วไปไม่ได้ สถานะงานยังเป็น research-only
