# RoadAware frontend (reserved)

โฟลเดอร์นี้สงวนไว้สำหรับเว็บไซต์ RoadAware ในอนาคต **ยังไม่มีหน้าจอ, ไม่มี scaffold และไม่มี dependency**

รวมถึง Dashboard สำหรับ Data Visualization ที่ผู้ใช้ขอให้ทำภายหลัง ข้อกำหนดและกระบวนการ Descriptive/Diagnostic/Predictive Analytics บันทึกใน [แผน Analytics และ Dashboard](../workflow/analytics-and-dashboard-plan-th.md) กราฟ EDA ใน backend เป็นหลักฐานตรวจข้อมูล ยังไม่ใช่ Dashboard

จะเริ่มได้หลังจาก:
- กำหนดความต้องการของผลิตภัณฑ์และเทคโนโลยีที่ใช้
- backend มีผลลัพธ์ที่ผ่านการตรวจแล้ว (ปัจจุบันความพร้อมของโมเดลจริง = BLOCKED ดู `../backend/README.md`)

ห้ามนำแอปหรือโมเดลจากโปรเจกต์เดิมมาใช้ซ้ำโดยไม่ผ่านการตรวจ
