# ขอบเขตความต่างจาก Google Maps และ Waze

ตรวจแหล่งทางการ11พฤศจิกายน2026 เพื่อใช้เตรียมคำอธิบายโครงการ ไม่ใช่ผลทดสอบว่า RoadAware แม่นยำกว่าระบบเชิงพาณิชย์

Google Maps มีการนำทางและรับรายงานเหตุบนเส้นทาง รวมถึงอุบัติเหตุ รถชะลอ งานก่อสร้างและการปิดช่องทาง ฟีเจอร์บางชนิดขึ้นกับประเทศ จึงไม่ควรนำเสนอว่าแผนที่เหล่านี้แสดงเพียงรถติดหรือไม่มีการแจ้งเหตุ [Google Maps Help](https://support.google.com/maps/answer/3273406?co=GENIE.Platform%3DAndroid&hl=en)

Waze มีการเตือนถนนที่มีประวัติอุบัติเหตุอยู่แล้ว เอกสารอธิบายว่าใช้รายงานผู้ขับขี่ร่วมกับบริบทเส้นทาง และการเตือนพิจารณาจราจร สภาพถนน วันและเวลา ดังนั้นข้อความว่า RoadAware ต่างเพราะใช้ AI/ประวัติอุบัติเหตุ/เตือนล่วงหน้าเพียงอย่างเดียวยังไม่เพียงพอ [Waze Help](https://support.google.com/waze/answer/13014546?hl=en) และ [ประกาศฟีเจอร์ปี2023](https://blog.google/waze/crash-history-alerts-arrive-to-the-waze-map/)

จุดที่โครงการนี้อธิบายและตรวจสอบได้คือการกำหนดปัญหาเป็น **Count Regression ของบันทึกอุบัติเหตุไทยที่เข้าเกณฑ์และเชื่อมกับช่วงถนนได้ ในวันหรือช่วง6ชั่วโมงที่ระบุ** พร้อมเปิดเผย lineage, ขอบเขตถนน, missing-data policy, temporal split, baseline, metric และ source code สำหรับรันซ้ำ โดยกำลังพัฒนาผลลัพธ์สำหรับต่อ frontend ให้แยกจำนวนย้อนหลัง ค่าคาดหมาย และข้อมูลที่ยังไม่ทราบอย่างชัดเจน นี่เป็นขอบเขตและแนวทางวิจัยของเรา ไม่ใช่หลักฐานว่าบริษัทอื่นไม่มีระบบภายในลักษณะเดียวกัน

| ประเด็นที่เล่าได้ | หลักฐานของ RoadAware | ขอบเขตคำกล่าว |
|---|---|---|
| เป้าหมายเป็นจำนวนบันทึกต่อช่วงถนนและเวลา | protocol/target definition,19sparsecounts,20experiments | ไม่ใช่โอกาสชนส่วนบุคคลหรืออุบัติเหตุจริงทั้งหมด |
| ทดลองโมเดลสามตระกูลและ baseline ตรวจซ้ำได้ | notebooks/config/tests/arrayshashes/metrics | ผลเป็น research backtest ของข้อมูลที่กำหนด ไม่ใช่การแข่งกับ Google/Waze |
| อธิบายประวัติประเภทเหตุและข้อมูลขาด | raw-description oracle ตรวจแล้ว; catalog14ยังต้องทำ | ยังไม่อ้างว่า endpoint/หน้าเว็บพร้อมใช้งาน |
| ระดับสีเทียบ reference เดียวกันและแสดงพื้นที่ไม่รองรับ | แผน21/22ที่ล็อกไว้; ยังไม่ตรวจรับ implementation | สีและการแสดงผลไม่ใช่นวัตกรรมที่พิสูจน์ความเหนือกว่าเอง |

ยังไม่มีการประเมิน RoadAware เทียบ Google Maps/Waze ด้วย ground truth และเงื่อนไขเดียวกัน จึงห้ามอ้างว่าลดอุบัติเหตุจริงหรือแม่นยำกว่า และยังไม่พิสูจน์ว่าความสามารถของคู่แข่งในไทยเหมือนทุกประเทศ
