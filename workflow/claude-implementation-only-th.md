# ข้อกำหนดผู้ใช้เพิ่มเติม — 11 พฤศจิกายน 2026

ผู้ใช้ย้ำระหว่าง actual20 กำลังรันว่า ต้องใช้ Claude ทำ ห้าม Codex แอบทำแทน

- Claude เป็นผู้เขียนและแก้โค้ดทั้งหมด รวม ML/backend/API/tests และสคริปต์เสริมใหม่
- Codex วางแผน เขียน task/เอกสาร อ่าน diff รันคำสั่งหรือสคริปต์ที่มีอยู่ และตรวจรับผล
- ห้าม Codex เขียนโค้ดแทนเมื่อ Claude quota เต็ม ต้องรักษางานและรอ reset ตามข้อกำหนดเดิม
- ได้แจ้งผู้ใช้แล้วว่า ก่อนย้ำข้อกำหนดนี้ Codex เคยเขียนเอกสารและสคริปต์ตรวจผลอิสระบางส่วน โค้ดโมเดลและ backend implementation ชุด20เป็นของ Claude ไม่เปลี่ยนประวัติหรืออ้างว่าสคริปต์เดิมเหล่านั้นเขียนโดย Claude
- หลัง reset ให้ Claude เขียน generic notebook payload assembler เพื่อให้ Codex เรียกคำสั่งประกอบ exact worker payloads ได้ โดยไม่ต้องเขียนสคริปต์ Python ใหม่เอง รวมถึงสคริปต์ตรวจผลเพิ่มเติมที่จำเป็น
